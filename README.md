# レシート家計簿

レシートの写真をアップロードすると、Claude API が商品名・金額・日付を読み取り、カテゴリ別に自動で分類して集計する家計簿Webアプリです。

## 主な機能

- レシート画像の自動読み取り（Claude Haiku）
- 読み取り結果の確認・修正をしてから登録
- カテゴリ別の円グラフ（月ごとに切り替え可）と月別の積み上げ棒グラフ
- データはブラウザのローカルストレージに保存（リロードしても消えません）

## セットアップ

1. Node.js 20 以上をインストールします。
2. 依存パッケージをインストールします。

   ```bash
   npm install
   ```

3. `.env.example` を `.env` にコピーし、`ANTHROPIC_API_KEY` に Claude の APIキーを設定します。
4. 開発サーバーを起動します。

   ```bash
   npm run dev
   ```

5. ブラウザで http://localhost:5173 を開きます。

## 本番起動

```bash
npm run build
npm start
```

http://localhost:3001 でアプリが開きます。

## 補足

- 対応している画像形式は JPEG・PNG・GIF・WebP です（iPhone の HEIC 形式は、ブラウザによっては読み込めません）。
- 画像は送信前にブラウザ側で縮小されます。
- データは使っているブラウザにだけ保存されます。別の端末やブラウザとは共有されません。
